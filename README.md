# Telegram Inline Photo Bot 📸

Бот для быстрой отправки вашей личной коллекции фотографий и картинок в любой чат Telegram в 1 клик через инлайн-режим (`@username_бота`).

---

## 🚀 Быстрый запуск на компьютере

### 1. Настройка окружения
В папке проекта уже создано виртуальное окружение `venv` со всеми установленными зависимостями.

Создайте файл `.env` рядом с `.env.example` (или скопируйте его):
```bash
copy .env.example .env
```

Откройте файл `.env` в блокноте или редакторе и заполните:
```ini
# Токен бота, полученный от @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Ваш числовой Telegram ID (узнать можно у бота @userinfobot или командой /myid)
ADMIN_ID=123456789

# Время кеширования инлайн-ответов в секундах (1 для моментального обновления)
CACHE_TIME=1
```

### 2. Запуск бота
В терминале внутри папки проекта выполните:
```bash
.\venv\Scripts\python bot.py
```

В консоли появится сообщение:
```
База данных SQLite инициализирована.
Бот @username_бота успешно запущен!
```

## 📱 Как пользоваться ботом

1. **Добавление фото**:
   - Напишите боту в личные сообщения (`/start`).
   - Просто **перетяните или отправьте картинку** боту в чат.
   - *Совет*: добавьте к фото подпись (например: `мем кот`, `реакция шок`). По этим словам потом можно будет искать конкретные картинки!
2. **Отправка в чатах (Инлайн-режим)**:
   - Откройте переписку с другом или любой групповой чат.
   - В поле ввода текста напишите: `@username_вашего_бота ` (с пробелом).
   - Выскочит всплывающая галерея со всеми вашими фото.
   - Нажмите на фото — оно моментально отправится в чат!
   - Если ввести слово для поиска: `@username_вашего_бота кот` — покажутся только фото со словом «кот» в описании.
3. **Управление коллекцией**:
   - Команда `/list` — выводит список добавленных фото с кнопками просмотра превью и удаления (`🗑`).
   - Команда `/count` — количество фото в коллекции.
   - Команда `/myid` — показывает ваш Telegram ID.

## 🌐 Бесплатный хостинг 24/7 (чтобы работал без включенного ПК)

Бот потребляет минимум ресурсов (~30-40 МБ ОЗУ) и моментально отвечает на запросы. Вот лучшие бесплатные способы держать его онлайн:

### Вариант 1: Koyeb (Рекомендуется, бесплатно навсегда)
1. Зарегистрируйтесь на [koyeb.com](https://www.koyeb.com/).
2. Загрузите код бота на свой [GitHub](https://github.com/) (без файла `.env` и папки `venv`).
3. В панели Koyeb нажмите **Create App** -> выберите **GitHub**.
4. Выберите репозиторий с ботом.
5. Во вкладке **Environment Variables** добавьте:
   - `BOT_TOKEN` = ваш токен
   - `ADMIN_ID` = ваш ID
6. Тип сервиса: **Worker** (или Web с командой запуска `python bot.py`).
7. Нажмите **Deploy**. Бот запустится и будет работать круглосуточно.

---

### Вариант 2: Render.com
1. Зарегистрируйтесь на [render.com](https://render.com/).
2. Залейте проект на GitHub.
3. В Render выберите **New +** -> **Background Worker**.
4. Подключите репозиторий.
5. Параметры:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
6. В разделе **Environment Variables** укажите `BOT_TOKEN` и `ADMIN_ID`.
7. Нажмите **Create Background Worker**.

---

### Вариант 3: Запуск в автозагрузке Windows (если ПК часто включен)
Если не хотите выкладывать код на GitHub, можно запускать бота автоматически в фоне при старте Windows:
1. Создайте в папке бота файл `start_bot.vbs` со следующим содержимым:
   ```vbs
   Set WshShell = CreateObject("WScript.Shell")
   WshShell.Run ".\venv\Scripts\python.exe bot.py", 0, False
   ```
2. Поместите ярлык этого файла в папку автозагрузки Windows (`Win + R` -> `shell:startup`).
3. Бот будет запускаться невидимо в фоновом режиме при каждом включении компьютера.
